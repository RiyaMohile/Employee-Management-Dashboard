# ⚡ EmpDesk - Employee Management Dashboard

A modern, feature-rich employee management dashboard built with **React 19**, **Tailwind CSS v4**, and **Lucide icons**. EmpDesk provides a beautiful interface for managing employee data with full CRUD operations, dark mode support, and responsive design.

## ✨ Features

### 🔐 Authentication
- Secure login system with demo credentials
- Protected routes for authenticated users
- Session persistence using localStorage
- Automatic redirect to login for unauthorized access

### 📊 Dashboard
- Real-time statistics cards (Total Employees, Active, Departments, Average Salary)
- Recent employees list with quick view
- Dynamic data updates
- Responsive grid layout

### 👥 Employee Management
- **Full CRUD Operations**: Create, Read, Update, Delete employees
- **Advanced Search**: Search by name or email
- **Filtering**: Filter by department and status
- **Sorting**: Sort by name, department, role, or salary
- **Pagination**: 8 employees per page with page navigation

### 🎨 UI/UX Features
- **Dark/Light Mode**: Toggle between themes with persistent preference
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Toast Notifications**: Success and error messages
- **Loading States**: Spinners during data fetch
- **Error Handling**: Graceful fallback to mock data on API failure

### 🎯 Technical Features
- Component-based architecture
- Context API for state management
- Axios for API integration
- Lucide React icons for professional look
- Custom Tailwind CSS styling
